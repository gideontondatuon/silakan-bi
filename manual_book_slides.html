Alur Kerja Sistem Terintegrasi (End-to-End)

1
Unit Kerja Memeriksa Kalender & Mengajukan

Cek ketersediaan jam di kalender visual, isi formulir rapat, dan unggah berkas disposisi resmi pimpinan (maks. 5 MB).

2
Verifikasi Disposisi & Persetujuan Admin

Admin sarpras memeriksa kelayakan permohonan. Admin berhak **Menyetujui** atau **Menolak** (wajib mencantumkan alasan resmi).

3
Notifikasi WhatsApp Gateway Instan

Sistem seketika mengirim konfirmasi persetujuan atau penolakan langsung ke nomor WhatsApp HP PIC unit pemohon.

4
Live TV Display & Laporan Eksekutif

Agenda otomatis tampil di layar TV lobi kantor, dan riwayat pemakaian dapat diekspor ke Excel & PDF Kop Resmi BI.

Prinsip Keterbukaan: Kalender dapat dilihat oleh seluruh pegawai agar koordinasi lintas unit lebih harmonis.

{{-- ============================================================ SLIDE 6: [USER 3] DISPOSISI & POPUP 5MB ============================================================ --}}
BAGIAN I: PANDUAN UNIT KERJA LANGKAH 3

Unggah Disposisi & Proteksi Validasi Maksimal 5 MB

1
Wajib Melampirkan Bukti Disposisi / Undangan

Sesuai tata kelola BI, pengajuan wajib menyertakan lembar disposisi pimpinan atau surat undangan resmi (Format: PDF, JPG, PNG).

!
Ketentuan Batas Ukuran File: Maksimal 5 MB

Untuk menjaga kestabilan dan kecepatan server kantor, berkas lampiran dibatasi maksimal berukuran 5 MegaByte (5 MB).

2
Proteksi Popup Otomatis

Jika pengguna memilih file di atas 5 MB, sistem langsung membatalkan pilihan berkas dan menampilkan Popup Peringatan Berwarna Merah.

Solusi File Besar: Kompres file PDF Anda atau ubah resolusi scan sebelum mengunggah ke sistem.
POPUP VALIDASI KEAMANAN FILE 5 MB
Notifikasi Popup Otomatis Bila Ukuran File Melebihi 5 MB

Fitur "Selesai Awal" & Pembatalan Mandiri

Fitur Unggulan: "Selesai Awal" (Early Finish)

1
Manfaat Efisiensi Aset Kantor

2
Hak Pembatalan Mandiri (*Cancel*)

Selama pengajuan masih berstatus Pending, unit kerja dapat membatalkan pesanan secara mandiri jika agenda rapat dibatalkan.

Notifikasi Real-Time: Setiap pembatalan atau selesai awal otomatis terekam ke sistem audit log admin.
