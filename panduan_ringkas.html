INFO Sekilas Tentang SILAKAN

SILAKAN (Sistem Informasi Layanan Kantor) adalah aplikasi berbasis website internal milik Bank Indonesia KPwBI Prov. Sulut yang digunakan untuk memesan dan mengelola ruangan rapat kantor secara online.

4 Manfaat Utama SILAKAN: 1. Bebas Bentrok: Sistem otomatis menolak jika ada yang memesan ruangan dan jam yang sama.
2. Jadwal Terbuka: Ketersediaan ruangan langsung terlihat pada kalender visual.
3. Konfirmasi Cepat WhatsApp: Pemohon langsung menerima notifikasi status persetujuan di WhatsApp.
4. Layar TV Lobby Otomatis: Agenda rapat aktif hari ini langsung tampil di TV Monitor Lobby kantor.

Langkah Menjalankan Sistem (Untuk Teknisi / Operator)

Jika aplikasi belum berjalan di laptop atau server kantor, lakukan 3 langkah mudah berikut:

1
Nyalakan Database MySQL (XAMPP)

Buka aplikasi XAMPP Control Panel, lalu klik tombol Start pada baris MySQL (pastikan lampu indikator berwarna hijau).

2
Jalankan Server Aplikasi (Laravel)

Buka Command Prompt di folder project d:\Bank Indo\silakan, lalu ketik perintah: php artisan serve. Server akan aktif di http://127.0.0.1:8000.

3
Buka Aplikasi di Browser (Google Chrome / Edge)

Akses alamat: http://localhost:8000 untuk login, dan http://localhost:8000/display untuk layar TV Lobby.

3. Cara Memesan Ruangan Rapat (Langkah Demi Langkah)

Klik tombol + Buat Pemesanan Baru pada Dashboard atau klik menu Pemesanan, lalu lengkapi isian formulir:

Gambar 1.4 — Formulir Pengajuan Pemesanan Ruangan Baru
  1. Ruangan Rapat: Pilih salah satu dari 11 ruangan rapat di KPwBI Sulut (Tondano, Bunaken, Tomohon, Klabat, Lokon, dll).
  2. Layout Ruangan: Pilih tata letak (U-Shape, Classroom, Teater, Round Table). Ruangan bertata letak tetap (seperti Bunaken) otomatis terisi *Tidak ada layout khusus*.
  3. Tanggal & Jam (WITA): Masukkan tanggal rapat serta jam mulai dan selesai (contoh: 09:00 s/d 11:30 WITA).
  4. Judul Kegiatan & PIC: Tuliskan nama agenda, nama penanggung jawab, kategori (Organik/Non Organik), dan Nomor WhatsApp PIC agar pemberitahuan otomatis bisa masuk.
  5. Jumlah Tamu: Masukkan jumlah peserta (sistem otomatis memvalidasi agar tidak melebihi kapasitas ruangan).
  6. Unggah Disposisi (Opsional): Lampirkan nota dinas pimpinan (PDF, JPG, PNG maks 5 MB), lalu klik Kirim Pengajuan Pemesanan.

4. Memantau Status Permohonan & Detail

Buka menu Riwayat untuk melihat perkembangan persetujuan ruangan Anda:

Gambar 1.5 — Riwayat Pemesanan Unit Kerja & Arti Badge Status
  • 🟡 PENDING: Sedang dalam antrean review Administrator Sarpras.
  • 🟢 DISETUJUI: Rapat disetujui! Ruangan resmi terkunci dan agenda muncul di TV Lobby.
  • 🔴 DITOLAK: Permohonan ditolak (klik tombol Detail untuk melihat alasan penolakan).
Fitur Pembatalan & Selesai Lebih Awal (Early Release): • Batalkan Rapat: Jika agenda batal, buka rincian detail pemesanan lalu klik tombol merah Batalkan Pemesanan.
• Selesai Lebih Cepat: Jika rapat bubar sebelum jam target, klik tombol hijau Selesaikan Rapat Sekarang agar ruangan di TV lobby seketika kosong kembali.

Buka menu Pemesanan Ruangan. Pada tab Pending, klik tombol Review Approval pada pengajuan yang masuk:

Gambar 2.2 — Review Berkas & Tombol Setujui
Gambar 2.3 — Modal Input Alasan Penolakan

4. Mengatur Master Data & Sinkronisasi Hari Libur

  • Data Ruangan: Tambah ruangan baru, ubah kapasitas, dan centang layout yang diizinkan menggunakan checkbox rounded badge.
  • Hari Libur: Klik tombol biru Sync API Libur Nasional untuk otomatis mengunduh tanggal merah pemerintah.
  • Data User: Buat akun unit kerja baru atau reset password pegawai yang lupa kata sandi.

5. Rekapitulasi Laporan, Ekspor Excel & Cetak PDF KOP BI

Buka menu Sistem → Laporan. Saring berdasarkan rentang tanggal atau ruangan, lalu klik Export Excel untuk mengunduh spreadsheet .xlsx atau klik Cetak Laporan / PDF untuk mencetak dokumen ber-KOP resmi Bank Indonesia.

Gambar 2.5 — Pratinjau Dokumen Cetak Laporan PDF Ber-KOP Resmi Bank Indonesia

TV Tampilan TV Monitor Lobby (Kiosk Mode)

Untuk menayangkan jadwal rapat pada Smart TV di lobby kantor:

  1. Buka browser TV atau Mini PC Lobby, lalu buka alamat: http://localhost:8000/display (atau /kiosk).
  2. Tekan tombol F11 di keyboard untuk layar penuh (*Full Screen*).
  3. Otomatis Memperbarui Setiap 30 Detik: Status ruangan yang terisi berwarna merah, dan ruangan kosong berwarna hijau secara mulus tanpa reload halaman (*zero-flicker*).
